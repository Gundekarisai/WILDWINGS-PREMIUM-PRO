# WILDWINGS HOTEL V2

A premium luxury hotel web application featuring an elegant modern UI, AI-powered chatbot assistance, smart room booking experience, dining and facilities showcase, responsive design, and seamless user interaction built using React, TypeScript, Tailwind CSS, and Vite.

---

## ✨ Features

- Premium luxury hotel UI
- AI-powered chatbot assistant
- Responsive modern design
- Smart room booking interface
- Dining showcase section
- Facilities management section
- Manager login page
- Smooth animations and transitions
- Fast performance using Vite
- Mobile-friendly experience

---

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Supabase
